# Post Composer

A small React app: write a post, pick Twitter (280) or LinkedIn (3000),
and see a live character count with an error when you go over.

## Run it

1. Install Node.js (v18 or newer): https://nodejs.org
2. Open this folder in VS Code
3. Open the terminal (Ctrl + `) and run:

    npm install
    npm run dev

4. Open the link it prints (usually http://localhost:5173)

The component is in `src/PostComposer.jsx`.
